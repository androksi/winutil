Use the **Features** and **Fixes** sections to install optional Windows components and run common repair tasks.

This page maps to the **Config** tab in WinUtil. Some actions complete immediately, while others may prompt, download files from Microsoft, or require a restart before the change is fully available.

![Config tab with features and fixes](../../../assets/screenshots/config-tab-new.png)

## Windows Features

Install common **Windows features** by selecting the feature checkboxes and clicking **Install Features**.

If a feature depends on Windows installation media or optional downloads, Windows may take longer to finish or request a reboot.

* All .NET Frameworks (2, 3, 4)
* Hyper-V Virtualization
* Legacy Media (WMP, DirectPlay)
* Enable Daily Registry Backup Task 12:30 AM
* Enable Legacy F8 Boot Recovery
* Disable Legacy F8 Boot Recovery
* Windows Subsystem for Linux
* Windows Sandbox

If an optional Windows feature is unavailable or fails to enable, WinUtil logs the failure and continues with the remaining optional features. Dependent setup scripts for that selection are skipped when an optional feature fails. The final job status still reports errors.

## Fixes

Use these one-click fixes for common system problems.

Use these when you have a specific issue to correct, not as a routine cleanup step.

* System Corruption Scan
* WinGet Reinstall

## Fonts

Select fonts and click **Install Fonts** to install them for your account only; other accounts on the PC are not affected and no administrator rights are used for the font itself.

* JetBrains Mono, Source Code Pro, Fira Code, Cascadia Code
* Nerd Fonts with terminal icons: JetBrainsMono, FiraCode, CaskaydiaCove, Hack, and Meslo

Each font is downloaded from the latest release of its official GitHub project, so some downloads are large (Cascadia Code and the JetBrainsMono and Meslo Nerd Fonts are over 100 MB). Static builds are installed when a release has them. A font file that is already installed is left as it is. Programs that were open during the install may need to be restarted to list the new fonts.

**Remove Fonts** removes the selected fonts, but only the files WinUtil installed; a font you installed another way stays. If a program still has a font open, that file is unregistered and removed the next time you click **Remove Fonts** after closing the program.

**Install Features** ignores selected fonts, and **Install Fonts** ignores selected Windows features. An exported configuration includes selected fonts, and `-Config` installs them.

## Legacy Windows Panels

Open old-school Windows panels directly from WinUtil. Available panels include:

* Control Panel
* Network Connections
* Power Panel
* Region
* Sound Settings
* System Properties
* User Accounts
